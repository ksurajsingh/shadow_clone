# V0.2 - EXPRESS

We now have achieved a TTA *time_to_access* of **15 mins** which is **87.5%**
faster as compared to v0.1 which required *~2 hours*.

check out [release notes](https://github.com/ksurajsingh/shadow_clone/releases/tag/v0.2)

We are still using external GUI builds [ref [v0.1](https://github.com/ksurajsingh/shadow_clone/releases/tag/v0.1) ].  
I plan to remove that in the future releases [mostly happening in Express versions] .

> P.S: I plan to have an INSTANT version as well - which would be faster than EXPRESS and more minimalistic.

> Usage 
```bash
curl -fsSOL https://raw.githubusercontent.com/ksurajsingh/shadow_clone/refs/heads/main/shadow_clone.sh
bash shadow_clone.sh

``` 
or  
```bash
wget -q https://raw.githubusercontent.com/ksurajsingh/shadow_clone/refs/heads/main/shadow_clone.sh
bash shadow_clone.sh
```
